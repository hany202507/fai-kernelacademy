# 워크플로 · 내부통제

updated: 2026-07-26 · 조합: **R→P→J→V→D** (C는 테스트 단계에 선택) · renders: T2 S5 맵 + S6 통제 설계 / YT "AI 시대의 내부통제"

## 대표 시나리오: 통제 매트릭스 수립·테스트 (+AI 사용 통제)

| 블록 | 작업 | 환경 |
|---|---|---|
| R | 통제 프레임(COSO·내부회계관리제도) 요건, 업종 리스크 사례 조사 | 무관 |
| P | 프로세스별 통제 매트릭스 초안(위험-통제 매핑), 통제 기술서 생성 | 로컬 |
| J | 위험 평가(중요도·발생가능성), 핵심통제 선정, 경영진·감사(위) 판단 영역 | 사람 |
| V | 통제 테스트, 표본 추출·증적 확인을 AI 보조로, 예외사항 집계 | 로컬 |
| D | 통제 문서화 패키지·운영 평가 보고 | 로컬 |

- **AI 시대의 신규 통제 영역 (S6 직결)**: AI 사용 자체가 통제 대상, 승인 도구 목록, 데이터 반출 기준, 실행환경 승인 목록, 산출물 검증 의무(V 블록의 제도화), 판단 로그 보존(J 블록의 제도화). **즉 6블록 규율을 조직 통제로 명문화한 것이 AI 사용 정책(AUP)이다.**
- **훈련 포인트**: 블록 문법과 통제 문법의 동형성, 개인의 좋은 습관(V·J)이 조직의 통제가 되는 경로.
- 실습 키트: 메종블룸 통제 매트릭스 템플릿, 구매-지급(OEM 발주·선급) + **입점사 정산 프로세스(예수금 통제) + 점포 현금·POS 통제**.
