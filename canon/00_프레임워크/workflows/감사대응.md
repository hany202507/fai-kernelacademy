# 워크플로 · 감사대응

updated: 2026-07-26 · 조합: **R→C→P→J→V→D** · renders: T2 S5 스튜디오 / YT "PBC 리스트를 AI로"

## 대표 시나리오: 외부감사 PBC(자료요청) 대응

| 블록 | 작업 | 환경 |
|---|---|---|
| R | 감사인 요청의 근거(감사기준·절차) 이해, 요청 항목별 필요 수준 파악 | 무관 |
| C | 요청 항목 ↔ 사내 자료 매핑(조서·원장·계약서·증빙), 자료 소재 인벤토리 | 로컬 |
| P | 자료 취합·목차화, 요청 대비 충족률 추적표, 사전 분석적 검토(감사인이 볼 것을 먼저 보기) | 로컬 |
| J | 민감 이슈 대응 방향, 쟁점의 설명 논리·제공 범위. 판단 로그 필수(감사 조서화) | 사람 |
| V | 제출 전 정합성, 제출 자료 간 상호 일치(같은 수치가 자료마다 다르면 최악), 재무제표와 대사 | 로컬 |
| D | PBC 제출 패키지 + 이슈별 설명 자료 + 대응 현황 보고(내부) | 로컬 제출 |

- **훈련 포인트**: "감사인이 물을 것을 먼저 검증한다", V 블록을 방어적으로 쓰는 법. 제출물 상호 정합성이 핵심 체크.
- **민감도 최상 등급 워크플로**, 클라우드 업로드는 원칙 금지, 전 과정 로컬. (실행환경 결정의 교육 사례)
- 실습 키트: 메종블룸 가상 PBC 리스트 30항목 + 불일치 심은 자료 세트. 쟁점 축: **수익 인식(총액/순액, 플랫폼 수수료), 예수금 실재성, 재고 실사(3종 재고), 지점 현금 통제**.
