# 워크플로 · 회계결산

updated: 2026-07-26 · 조합: **C→P→J→V→D** (+월중 수시 R) · renders: T2 S3 훈련 / T1 L3 / YT "월결산을 AI와"

## 대표 시나리오: 월결산

| 블록 | 작업 | 환경 |
|---|---|---|
| C | 원장·은행거래·카드 연동, 기초잔액 확인, 원본 대사 | 로컬 우선 |
| P | 미결 거래 분류·분개 생성 → 시산표 → 재무제표 초안 (계산은 수식) | 로컬 |
| J | 결산조정 판단, 발생·이연, 계정분류, 충당 설정. 전기 판단 승계 확인 | 로컬 |
| V | **tie-out**(FS↔시산표↔원장), 이상 계정 리뷰, 전기 대비 분석적 검토, **골든셋 채점**(전기 확정 결산=정답표) | 로컬 |
| D | 결산보고 패키지, 재무제표 + 증감 분석 + 경영진 요약 | 하이브리드 |

- **훈련 포인트**: 골든셋 루프의 본거지, 오분류를 규칙으로 승격해 지시서 v2를 만드는 사이클을 여기서 체득.
- **드릴**: 오류를 심은 다른 월 데이터로 재수행 (검증 재현성).
- 실습 키트: 메종블룸 3개월 원장 + 전기 확정 결산(골든셋) + 심은 쟁점: **채널별 정산 대사 차이(PG 수수료 누락), 입점 판매대금의 예수금 처리, 시즌오프 재고 평가**.
