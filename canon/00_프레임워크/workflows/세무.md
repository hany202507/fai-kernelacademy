# 워크플로 · 세무

updated: 2026-07-26 · 조합: **R→C→P→J→V→D** (6블록 전부 사용, 교육의 첫 완주 시나리오) · renders: T2 S4 완주 / T1 L4 맛보기 / YT 데모

## 대표 시나리오: 부가세 신고 (분기)

| 블록 | 작업 | 환경 |
|---|---|---|
| R | 쟁점 거래의 공제 요건·예규 조사 (원문 확인, "확인 불가" 규칙) | 무관 |
| C | 매입매출·카드·현금영수증 데이터 연동, 원본 대사 | 로컬 우선 |
| P | 매입세액 공제/불공제 1차 분류 (불공제 체크리스트 전수 적용, 모호=보류) | 로컬 |
| J | 보류 건 판단 확정, AI는 양쪽 논거, 결정은 사람. 판단 로그 기록 | 로컬 |
| V | 신고서-장부 대사, 세액 독립 재계산, 인용 조문 원문 확인 | 로컬 |
| D | 신고서 초안(파일링) + 내부보고(요약·리스크), 이원 산출 | 신고=서식 / 보고=하이브리드 |

- **변형**: 원천세(월), 같은 조합, P가 급여·소득 구분 계산으로. / 법인세(연), R·J 비중 증가.
- **훈련 포인트**: 보류율의 적정선(과소=위험, 과다=무의미), 판단 로그가 다음 분기를 얼마나 줄이는지 체감.
- 실습 키트: 메종블룸 채널별 매출(자사몰·플랫폼·오프라인)·입점 수수료 세금계산서·카드 매입 + 심은 쟁점: 불공제 매입(접대성 협찬), 카페 겸영, 파트타임 일용 원천세 누락.
