# 워크플로 · 보고

updated: 2026-07-26 · 조합: **C→P→J→V→D** · renders: T2 S4 대시보드·S5 / YT "경영진이 다시 물어보지 않는 보고서"

## 대표 시나리오: 월간 경영 보고 (대시보드 + 커멘터리)

| 블록 | 작업 | 환경 |
|---|---|---|
| C | 확정 시산표·KPI 원천(매출·자금·인원) 연동, **V 통과본만 입력** | 로컬 |
| P | 대시보드 생성(v1→v3 반복), 증감 분석, 커멘터리 초안 | 로컬 생성 |
| J | 핵심 메시지 선정, 무엇을 강조하고 무엇을 각주로 내릴지, 해석의 책임 | 사람 |
| V | 수치 전수 대사(대시보드↔원천), 사실/해석 구분 검토 | 로컬 |
| D | 수신자별 렌더링, 경영진(요약+시사점) / 부서(상세) / 이사회(공식) | 하이브리드(요약만 게시) |

- **훈련 포인트**: 같은 데이터의 수신자별 3종 렌더링, D 블록의 정보 수준 규칙 체득. 대시보드 반복(v1→v3)이 Description–Discernment 루프의 가장 눈에 보이는 실습.
- **런타임 사례**: 상세=로컬 아티팩트, 경영진 요약 대시보드=클라우드 게시(민감 상세 제거 후), 하이브리드의 교과서 케이스.
- 실습 키트: 메종블룸 확정 시산표 + KPI 시트, **채널별(자사몰·플랫폼·오프라인·F&B) 손익 + 점포별 손익 + CCC 대시보드·성장률 시뮬레이터** 표준 실습 연계.
