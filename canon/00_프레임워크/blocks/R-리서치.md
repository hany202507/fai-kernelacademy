# R 리서치 블록

updated: 2026-08-12 · renders: 책 2부 / T2 S2 / YT "AI에게 세법 물어보면 안 되는 이유(그리고 되는 방법)"

## 정의
법령과 기준, 정책과 사례에서 **근거를 확보**하는 단계. 재무 업무의 판단은 근거 위에서만 선다.

## 역할 분담
- **AI**: 검색·요약·조문 후보 제시·인용
- **사람**: 근거의 채택. 어떤 조문과 기준을 이 사안의 근거로 삼을지 결정한다

## 핵심 규칙
1. **"원문 없으면 확인 불가"**, AI가 인용한 조문·예규는 반드시 원문(법제처·기준서)으로 확인. 원문을 못 찾으면 결론에 쓰지 않고 "확인 불가"로 표기한다.
2. 시행일·개정 이력 확인, 지금 유효한 조문인가.
3. 권위의 위계, 법령 > 시행령·규칙 > 예규·해석 > 실무 관행 > 블로그. AI는 위계를 섞는다.

## 표준 지시서 골격
```
[사안] ~에 대해 조사하라.
[요구] ① 근거 조문·기준서 문단을 번호까지 인용 ② 원문 링크 표기
③ 유효 시행일 명시 ④ 근거를 못 찾으면 "확인 불가"로 표기하고 추정하지 말 것
[산출] 사안 요약 / 근거 목록(위계 표기) / 반대 견해·리스크 / 확인 불가 항목
```

## 검증 체크 (V 연결)
- [ ] 인용 조문을 원문과 대조했는가 (문구 일치·조번호 실재)
- [ ] 시행일이 사안의 귀속 시기와 맞는가
- [ ] 출처 위계가 결론의 무게와 맞는가

## 실패 사례
- 환각 조문: 존재하지 않는 "부가가치세법 제XX조의3" 인용, 그럴듯한 형식이 함정
- 폐지된 예규를 현행으로 인용 / 외국 세법 논리를 국내에 혼입
