# C 연동 블록

updated: 2026-08-12 · renders: 책 2부 / T2 S2 (조기 배치) / YT "복사-붙여넣기 그만: MCP"

## 정의
업무 데이터를 AI에게 **가져다주는** 단계. 파일 업로드부터 MCP와 시스템 연동까지 다룬다. 손으로 옮겨 붙이는 작업을 없애는 것이 목표다.

## 역할 분담
- **AI**: 연결된 데이터의 자연어 조회·요약·필터
- **사람**: **연결 범위의 결정.** 무엇을, 어느 환경에서, 어디까지 연결할지가 곧 보안 게이트다

## 핵심 규칙
1. **연결 전 데이터 등급 확인**, 데이터 분류표(S1)에서 등급 판정 후 연결. 금지 등급은 마스킹·집계 후에만.
2. **연결 후 원본 대사**, AI가 조회한 결과의 합계·건수를 원본과 대사한 뒤 신뢰 시작.
3. 연결은 최소 범위로, 필요한 폴더·기간·계정만 (과잉 연결 금지).
4. 실행환경 결정과 한 몸, 로컬 MCP인가, 클라우드 커넥터인가 ([runtime.md](../runtime.md)).

## 연동 수준 사다리 (교육 순서)
① 파일 첨부(수동) → ② 스프레드시트·드라이브 커넥터 → ③ 회계데이터 MCP(은행·매입매출) → ④ 법령 DB MCP → ⑤ 세컨드브레인 볼트 연결 → (심화) 사내 시스템 API

## 표준 지시서 골격
```
[연결] ~커넥터의 ~범위(기간·계정)만 사용하라.
[조회] ~을 집계·필터하라. [대사] 결과의 총건수·합계를 함께 보고하라.
[금지] 연결 범위 밖 데이터 접근·추론 금지. 개인정보 컬럼은 무시하라.
```

## 검증 체크 (V 연결)
- [ ] 조회 합계·건수 = 원본 합계·건수
- [ ] 기간·범위 필터가 지시대로 적용됐는가
- [ ] 민감 컬럼이 산출물에 노출되지 않았는가

## 실패 사례
- 전체 드라이브 연결 → 급여 파일까지 컨텍스트 유입
- 대사 없이 조회 결과 신뢰 → 중복·누락 상태로 보고서 작성

## 도구·환경 (빠름층)
MCP 커넥터 카탈로그(드라이브·시트·회계데이터·법령·노션/옵시디언). 민감 데이터는 로컬 MCP 우선 `[민감도가 환경을 결정]`
