## 운영 규칙

1. **수정은 canon 먼저.** 강의·영상에서 발견한 개선은 canon에 반영 후 파생물 갱신. 파생물에만 고치면 다음 렌더링에서 유실된다.
2. 각 파일 상단에 `updated:` 날짜. 도구·환경 층은 `확인일`도 병기 (6개월 경과 시 재확인, reference-db 규칙과 동일).
3. **책에는 느림층만.** 빠름층(도구 how-to)을 책에 넣지 않는다. 인쇄 순간 낡는다.
4. 블록·워크플로 파일의 스키마를 유지한다 (정의 → AI/사람 역할 → 핵심 규칙 → 표준 지시서 골격 → 검증 체크 → 실패 사례 → 도구·환경 → 렌더링 노트).
5. 교육위원 검토(서면·회의)의 반영 로그는 각 파일 하단에 `> 검토반영:` 인용구로 누적.
