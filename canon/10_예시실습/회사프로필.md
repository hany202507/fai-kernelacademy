# 가상 회사 프로필 · (주)메종블룸 (가칭)

updated: 2026-07-26 · 전 과정 관통 실습 회사. 구 「한빛무역」(무역업 단일 모델) 대체, 멀티채널 브랜드 기업으로 전면 재설계.

## 회사 개요

**화장품·패션을 생산·판매하는 브랜드 기업.** 자사몰을 플랫폼으로 운영하며 타 브랜드 입점도 관리하고, 자사 화장품·의류를 판매하는 플래그십 카페(F&B) 점포 2개를 운영한다.

| 항목 | 설정 |
|---|---|
| 매출 | **연 300억 원**, 매년 **30~50%+ 성장** (고성장 스케일업) |
| 사업 1, 브랜드 | 화장품(OEM 생산)·패션(자체 기획+외주 생산), 자사몰 D2C + 외부 플랫폼 입점 판매 |
| 사업 2, 플랫폼 | 자사몰에 타 브랜드 입점 유치 → **판매수수료 수익 + 입점사 정산 관리** |
| 사업 3, 오프라인 | 플래그십 스토어 2개점 = 자사 제품 리테일 + **카페(F&B)** 복합 |
| 조직 | 본사(기획·마케팅·물류·경영지원) + 점포 2곳(정규+파트타임) |

## 왜 이 회사인가, 교육적 설계 의도

성장하는 커머스·브랜드 기업은 재무 난제의 종합 선물세트다. 7대 워크플로가 전부 "진짜 문제"를 갖는다:

| 재무 특성 | 만들어지는 교육 포인트 | 블록 |
|---|---|---|
| **채널별 정산 주기 상이**, 자사몰 PG(D+2~7), 외부 플랫폼(월 2회), 오프라인 카드/현금 | 매출 인식 vs 입금 시차, **채널별 정산 대사**, V블록의 천국 | V·C |
| **입점사 정산**, 판매대금은 예수금(부채), 수수료만 수익 | **총액/순액 수익 인식 판단**, 예수금 관리, 회계기준 판단의 대표 사례 | J |
| **재고 3종**, 화장품(유통기한), 패션(시즌성·시즌오프 평가손), F&B 원재료 | 재고자산 평가·폐기 판단, 발주 계획 | J·P |
| **고성장 운전자본 압박**, 재고 선투자·OEM 발주 선급 vs 정산 입금 시차 | **CCC(현금전환주기)·자금 시뮬레이션이 생존 문제**, 성장률 30~50%의 역설(이익 나도 현금 마름) | 자금 WF |
| 광고선전비 대량 집행 (미디어커머스) | 채널별 ROAS·예산 통제, 비용 분류 | 예산 WF |
| 부가세 복잡도, 다채널 과세 매출 + 입점 수수료 세금계산서 + 카페 겸영 | 채널별 매출 집계·수수료 세금계산서 검증 | 세무 WF |
| 점포·파트타임 급여 | 일용·단시간 원천세, 점포별 인건비 배부 | 세무 WF |
| 다점포 손익 + 채널별 손익 | 부문 손익·배부 기준, 보고·예산의 실전 재료 | 보고 WF |

수강생 대부분(중소·중견 재무팀, 기장 사무소 고객사)이 커머스·리테일 접점을 가지므로 체감 정합성도 높다. 기존 세종대 CCC 대시보드·성장률 시뮬레이터 자산과 직결.

## 데이터 키트 구성

**파일 키트 (T1·T2 공용)**: 기초 재무제표 / 3개월 원장 / 은행 입출금(계좌 4: 운영·PG정산·급여·예비) / 카드 매입 / 세금계산서(매출·매입) / 급여대장(본사+점포·파트타임) / OEM 발주·재고 수불부 / 입점사 정산 내역 / 임대차계약(점포 2) / 거래처 마스터 / 연간 예산

**BigQuery 확장 (AI CFO Lab, T2)**: 자사몰 주문 수십만 건(수년치) / PG 정산 상세 / 입점사별 판매·정산 / POS 거래(2개점, 리테일+F&B 구분) / 재고 이동 / 광고비 집행 로그 / 원장 전표 / 예산·실적 큐브

**심어둘 시나리오(오류·쟁점)**: 정산 대사 차이(PG 수수료 누락 건), 총액 인식 오류, 시즌오프 재고 평가 누락, 불공제 매입(접대성 협찬), 일용직 원천세 누락, 점포 간 재고 이동 미기록, 예산 초과 광고 집행 등, 각 워크플로의 V·J 훈련 재료.

> 회사명·수치 상세(제품 라인, 입점사 수, 점포 위치 등)는 키트 제작 시 확정. 명칭 「메종블룸」은 가칭, 상표·실존 기업 충돌 확인 후 확정.
