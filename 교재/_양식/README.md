# 양식

새 과정을 시작할 때 이 폴더를 통째로 복사해 과정 이름으로 바꿉니다.

```bash
cp -r 교재/_양식 교재/T2_회계결산
```

복사한 뒤 `_양식/README.md`(이 파일)는 지웁니다.

| 파일 | 채우는 순서 |
|---|---|
| `과정_README.md` | 1. 과정 한 장 요약 |
| `02_슬라이드구성.md` | 2. 슬라이드부터 짭니다 — 여기서 장 번호가 확정됩니다 |
| `01_설명_원고.md` | 3. 슬라이드 번호를 받아 설명을 씁니다 |
| `03_실습데이터/README.md` | 4. 실습 |

**슬라이드를 먼저 짭니다.** 설명 리포트의 3장이 슬라이드 번호를 참조하므로,
설명을 먼저 쓰면 번호가 바뀔 때마다 두 문서를 같이 고쳐야 합니다.

규칙 전문은 [../README.md](../README.md).
