# 레이아웃·인쇄 레퍼런스

SKILL.md 는 **판단이 갈리는 것**만 담는다. 이 파일은 템플릿 CSS 가 이미 강제하고 있는 것들의 해설이다.
평소에는 읽을 필요가 없다. **직접 CSS 를 건드려야 할 때, 또는 실측이 이상할 때** 편다.

---

## 1. 간격은 층위다

아래로 갈수록 넓어지는 사다리를 유지한다. **어느 한 칸만 넓히면 그 칸이 도리어 뭉쳐 보인다** — 소제목 '앞'만 넓히고 '뒤'를 문단 간격과 같게 두면, 소제목이 아래 본문에 달라붙어 한 덩어리가 된다.

| 층위 | 화면 | 인쇄 | 선택자 |
|---|---|---|---|
| 문단 ↔ 문단 | 28px | 12pt | `.doc p` |
| 소제목 → 첫 본문 | 36px | 16pt | `.sec > h3 + *` |
| **블록 ↔ 블록 / 블록 → 문단** | **46px** | **20pt** | `:is(블록) + :is(블록, p)` |
| 소제목 앞(절 경계) | 108px | 36pt | `h3` |
| 장 머리 → 첫 소제목 | 116px | 42pt | `.sech + h3` |
| **장 머리 뒤(예외: 좁게)** | **32px** | **13pt** | `.sech` |

인쇄 값은 전부 `--pgap` 배율을 탄다. **페이지가 넘치면 이 값이 아니라 `--pgap` 을 낮춘다.**

**마지막 줄만 사다리를 거스른다.** 장 머리 뒤 도입 문단은 '장의 서문'이라 헤어라인에 붙어 있어야 장 머리의 일부로 읽힌다. 여기를 넓히면 그 문단이 어느 절에도 속하지 않은 채 공중에 뜬다. 그래서 `.sech` 아래는 좁게 두고, **곧바로 소제목이 오는 경우만** `.sech + h3` 로 크게 벌린다.

**시각 블록이 연달아 오면 따로 벌린다.** 표 뒤 콜아웃, 카드 뒤 단계처럼 블록이 붙어 나오면 각자의 `margin-top` 만으로는 둘이 한 덩어리로 보인다. 템플릿에 인접 규칙이 있다 — **새 컴포넌트를 만들면 `:is()` 목록 양쪽에 클래스를 추가해야** 간격이 따라온다. 표 주석(`.doc p.cap`)은 명시도가 높아 표에 붙은 채로 남는다.

---

## 2. 인쇄에서 템플릿이 이미 보장하는 것

손으로 바꾸지 않는다.

- **장(`h2`) 하나가 새 페이지에서 시작** — `.sec{break-before:page}`. 표지+요약이 1쪽, 01장이 2쪽.
- **시각 블록은 '그림 한 장'** — `tw`·`cards`·`stats`·`steps`·`kv`·`callout`·`quote`·`code`·`banner`·`summary` 는 통째로 `break-inside:avoid`.
  - Chrome 은 flex/grid 컨테이너의 `break-inside:avoid` 를 무시한다. 그래서 인쇄에서만 `.steps{display:block}` 으로 되돌린다(보이는 모양은 같다).
- **소제목은 뒤에 오는 것과 붙어 다닌다** — `h2`/`h3`/`h4` 는 `break-inside:avoid` + `break-after:avoid`. 여기에 더해 **시각 블록 바로 앞 문단**도 그 블록과 붙는다(`p:has(+ .steps)` 등).
- **불릿·번호 목록(`pts`/`nums`)도 통째로 유지**된다.
- **표·그림 주석은 `.figw` 로 묶는다.** `.cap{break-before:avoid}` 만으로는 표가 페이지를 꽉 채웠을 때 브라우저가 규칙을 포기해 주석이 떨어진다. **감싸야 확실하다.**
- **페이지 번호는 하단 가운데**에 CSS 가 찍는다(`@page{@bottom-center}`).
- 배경·색상은 `print-color-adjust:exact` 로 강제된다.
- 한글은 `word-break:keep-all` 로 어절 중간에서 잘리지 않는다. 표 첫 열은 `white-space:nowrap`.

### 함정: `p:has(+ h3)` 를 걸지 마라

그 `p:has()` 목록에 `h3`/`h4` 를 넣으면 안 된다. 문단은 '앞' 소제목에 속하지 '뒤' 소제목에 속하지 않는다. 걸면 avoid 가 연쇄해 「앞 절 마지막 문단 → 소제목 → 도입 문단 → 그림」이 통째로 분리 불가 덩어리가 되고, 다음 페이지로 밀리면서 **앞 페이지가 크게 빈 채 남고 본문 문단이 페이지 맨 위에서 시작한다.**

- **증상 판별**: 채움률이 낮은 페이지의 **다음 페이지가 본문 문단으로 시작**하면 이 연쇄를 의심한다. 소제목으로 시작하면 정상적인 절 경계다.
- 소제목이 페이지 끝에 홀로 남는 것은 `h3` 자신의 `break-after:avoid` 가 이미 막으므로 이 고리는 필요 없다.

## 3. 크기 손잡이 네 개

전부 `@media print` 의 `:root{...}` 한 줄에 모여 있고 **문서 전체에 걸린다.** 한 페이지만 고치는 용도가 아니다.

| 손잡이 | 범위 | 언제 |
|---|---|---|
| `--pgap` | 0.55 ~ 1.15 | **가장 먼저 만진다.** 여백 배율 |
| `--pfs` | 9.8 ~ 11pt | 본문 크기. 0.2pt 단위로 |
| `--ph3` | 12 ~ 14pt | 소제목이 본문 대비 커 보일 때만 |
| `--ph2` | 17 ~ 21pt | 장 제목 |

**범위를 벗어나야 맞는다면 크기가 아니라 분량이 잘못된 것이다.**

`--pgap` 의 정상 범위는 스킨마다 다르다. 장식을 걷어낸 이 스킨은 블록이 얇아 **1.0~1.15** 가 정상이다(기준 문서 8쪽 실측: 1.1 에서 통과). 그라데이션 막대·그림자가 있던 옛 스킨의 0.55~0.8 을 그대로 가져오면 지나치게 촘촘해진다.

## 4. 덩어리 크기

묶이는 단위는 **「소제목 + 그림 + 주석」한 덩어리**다. 이 덩어리가 A4 한 페이지보다 커지면 브라우저가 `avoid` 를 포기하고 **가장 보기 싫게** 쪼갠다.

- `steps` 는 한 블록에 **6단계 이하**, 각 단계 설명 2~3줄
- 표는 **12행 이하**, 카드는 한 줄에 2~3장
- 표 주석은 **4줄 이내** — 그보다 길면 「표+주석」이 한 페이지를 넘겨 오히려 갈라진다(실측 확인)
- 표 첫 열은 **12자 이내 짧은 라벨**. 줄바꿈되지 않으므로 긴 문장을 넣으면 표가 옆으로 넘친다. 꼭 필요하면 그 칸에만 `<td class="wrap">`
- 덩어리가 커서 통째로 다음 장으로 밀리면 **그림 쪽을 줄이는 것이 먼저다**(항목 수·설명 길이·행 수). 앞쪽 서술을 늘려 공백을 메우는 땜질을 먼저 하지 않는다

## 5. 실측기가 거짓말하는 두 경우

`printcheck.ps1` 은 PDF 의 텍스트 스트림을 세어 페이지를 나눈다. 그 가정이 깨지는 상황이 둘 있다.

**(1) `opacity` 를 쓰면 페이지가 0쪽으로 보고된다.**
인쇄 시 합성 레이어가 생겨 그 글자만 독립 스트림이 되고, '스트림 하나 = 페이지 하나' 가정이 한 칸씩 밀린다. 결과는 오류가 아니라 **조용한 0쪽**이라 놓치기 쉽다. 흐리게 하려면 `opacity` 가 아니라 **색**으로 흐리게 한다.

**(2) `sec cont` 로 장 경계를 없애면 '통과' 가 찍힌다.**
이 스크립트는 우선순위표의 7번(채움)만 본다. 장이 새 페이지에서 시작하는지는 **검사하지 않는다.** 그 통과는 가짜다.

## 6. `.ps1` 파일에는 BOM 이 필요하다

PowerShell 5.1 은 BOM 없는 `.ps1` 을 ANSI 로 읽는다. 한글 주석이 깨지면서 **파서 오류**가 난다(문자열 종결자 없음, 예기치 않은 토큰…). 이 스킬의 스크립트를 새로 만들거나 다른 도구로 저장했다면 UTF-8 **with BOM** 인지 확인한다.

```bash
head -c 3 assets/printcheck.ps1 | xxd   # efbb bf 여야 한다
```
