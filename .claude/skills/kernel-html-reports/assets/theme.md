# 테마 토큰 — 정본

이 표가 색의 유일한 출처다. **템플릿의 `:root` 블록 밖 어디에도 색 리터럴을 쓰지 않는다.**
스킬 본문·컴포넌트 스니펫·산출 마크업은 전부 토큰 이름만 부른다.

## 값

```css
:root{
  --bg:#FFFFFF;       /* 바탕. 순백 — 그라데이션 면을 쓰지 않는다 */
  --card:#FFFFFF;
  --tint:#F7F9FC;     /* 면을 아주 옅게 눕힐 때만 */
  --ink:#0A1628;      /* 제목 */
  --body:#39445A;     /* 본문 */
  --muted:#6B7688;    /* 보조 */
  --faint:#9AA3B2;    /* 라벨 */
  --line:#E3E7EE;
  --line2:#F1F3F7;
  --rule:#0A1628;     /* 표·요약 위에 긋는 굵은 규칙선 */

  --a1:#1E50D8; --a1t:#1741B4; --a1b:#EAF0FF;   /* 블루 */
  --a2:#4338CA; --a2t:#332BA6; --a2b:#EDEBFD;   /* 인디고 */
  --a3:#C2761A; --a3t:#96590F; --a3b:#FBF1E1;   /* 앰버 */
  --risk:#D4453B; --riskT:#B5322A; --riskB:#FDECEA;

  --sh:0 1px 2px rgba(10,22,40,.04);
  --sh-sm:0 1px 2px rgba(10,22,40,.035);
}
```

## 역할

| 토큰 | 무엇에 | 바꿔도 되는가 |
|---|---|---|
| `--a1 / --a2 / --a3` | 장(章) 순환 액센트. 고스트 번호·규칙선·라벨 | 교체 가능 |
| `--a1b / --a2b / --a3b` | 그 색의 **옅은 채움**. 고스트 번호와 톤 콜아웃이 쓴다 | 함께 교체 |
| `--risk` 계열 | 경고 전용. **순환에 넣지 않는다** | 교체 가능 |
| `--rule` | 표 머리·요약 위의 굵은 선 | 교체 가능 |
| `--ink / --body / --muted / --faint` | 글자 위계 4단 | 대비를 확인하고 교체 |
| `--pgap / --pfs / --ph2 / --ph3` | 인쇄 여백·크기 손잡이(`@media print`) | **실측 없이 바꾸지 않는다** |

## 스타일을 갈아끼울 때

1. 위 블록만 바꾼다. 다른 규칙은 손대지 않는다.
2. `printcheck.ps1`을 **다시 돌린다.** 색만 바꿔도 서체 크기를 함께 건드렸다면 페이지 수가 달라진다.
3. `--pgap`의 정상 범위를 새로 재서 이 파일에 적는다. **옛 숫자는 옛 스킨의 것이다.**

현재 기준 문서(`reference/기준_보고서.html`, 8쪽) 실측값: `--pgap:1.1` 에서 전 페이지 채움률 55~90%, 판정 통과.

## 자매 스킬과의 동기화

`kernel-html-slides` 의 템플릿에도 **같은 블록이 들어 있다.** 산출물이 단일 파일이어야 하므로 CSS를 공유 파일로 뺄 수 없다 — 대신 두 곳을 함께 고친다.

바꾼 뒤 어긋났는지 확인:

```bash
diff <(sed -n '/^  :root{/,/^  }/p' ~/.claude/skills/kernel-html-reports/assets/template.html) <(sed -n '/^  :root{/,/^  }/p' ~/.claude/skills/kernel-html-slides/assets/template.html)
```

출력이 비어야 정상이다.
