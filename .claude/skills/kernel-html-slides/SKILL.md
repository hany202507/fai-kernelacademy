# kernel-html-slides

입력 문서를 **1280×720 고정 캔버스의 단일 파일 HTML 슬라이드**로 만든다.
디자인은 `assets/template.html` 에 박제돼 있다. 완성형은 `reference/기준_슬라이드.html` — **막히면 그것을 편다.**

자매 스킬 `kernel-html-reports` 와 같은 토큰을 쓴다(`assets/theme.md`).

## 절대 원칙

1. **디자인을 발명하지 않는다.** 색·간격·컴포넌트는 템플릿 CSS 만 쓴다. 새 클래스·색 리터럴을 만들지 않는다.
2. **캔버스는 1280×720 고정.** 내용이 넘치면 **폰트를 줄이지 말고 슬라이드를 나눈다.**
3. **단일 파일.** 외부 리소스는 Pretendard 폰트 CDN 하나뿐.
4. **이모지 미사용.**
5. **내용을 지어내지 않는다.** 문구는 입력 문서에서 나온다. 요약·재배치는 하되 없는 사실을 만들지 않는다.
6. **넘침은 눈으로 판정하지 않는다.** `.slide` 는 `overflow:hidden` 이라 **넘친 줄은 그냥 안 보인다** — 한 줄이 잘려 나가도 화면은 멀쩡하다. `slidecheck.ps1` 로 잰다.
7. **한 요소의 색은 한 곳에서만 드러낸다.** 장의 색은 고스트 번호가 진다. 제목에 밑줄을, 카드에 막대를 겹치지 않는다.
8. **문장도 발명하지 않는다.** 제목·부제·배너는 자리마다 담을 것이 정해져 있다 — `assets/tone.md`. 원본 문서에 있던 문장은 사용자 문장이니 다시 쓰지 않는다.

## 절차

### 1. 입력 확보
변환할 문서를 확인한다. 제목·부제, 청중, 원하는 분량이 있으면 반영하고 없으면 문서 구조에서 추론한다.

### 2. 구조 설계 (만들기 전에)
권장 뼈대: **표지**(cover) → **목차**(agenda, 부/장이 3개 이상일 때) → 부마다 [**구분**(cover) → **본문** 여러 장] → **마무리**(cover).

**본문 한 장의 핵심 요점은 2~4개.** 그보다 많으면 나눈다.

| 내용 성격 | 컴포넌트 |
|---|---|
| 두 개념 대비·비교 | `duo` (2단 패널) |
| 3~4개 병렬 항목 | `cards` |
| 순서·단계 | `flow` 또는 `map` (가로 로드맵) |
| 용어 정의 5~6개 | `wide` + `deflist` |
| 목록형 한 덩어리 | `wide` 패널 1개 |
| 한 문장 결론 | `banner` |

세부 마크업은 `assets/components.md`.

### 3. 채우기
- `assets/template.html` 을 산출 파일로 복사(예: `<문서명>_슬라이드.html`).
- **예시 슬라이드를 전부 지우고** 설계한 슬라이드로 `<div class="deck">` 를 채운다.
- `{{DECK_TITLE}}`·`{{부제}}` 등 `{{...}}` 를 전부 치환한다.
- 첫 슬라이드에만 `class="slide cover active"` 의 `active` 를 남긴다.
- **본문 슬라이드 머리에는 `data-n` 을 준다** — `<div class="head" data-n="01">`. 왼쪽 여백의 고스트 번호가 여기서 나온다. 표지·구분 슬라이드에는 주지 않는다.
- 모든 cover 계열에 `class="... cover"` 가 있는지 확인한다(가운데 정렬 + 부 경계 판정이 이걸 읽는다).
- **부 구분 슬라이드의 eyebrow 는 `<b>제N부 · 이름</b>` 으로 시작한다.** 좌하단 부 표시와 부 진행바 칸 수가 이 문자열에서 나온다. `제N부` 로 시작하지 않는 cover(표지·목차·마무리)는 부를 닫는다.
- 색은 `a1 → a2 → a3` 순환. 경고는 `risk`.
- 문구는 `assets/tone.md` 의 자리별 규칙대로 쓴다. 제목은 사실(숫자 → 벌어진 일 → 명사구) 순으로 고른다.
- 등장 순서대로 `data-anim style="--d:N"` 을 0부터 매긴다.

### 4. 실측 (필수)
```
powershell -ExecutionPolicy Bypass -File <스킬>/assets/slidecheck.ps1 "<C:\절대\경로\슬라이드.html>"
```
슬라이드마다 가장 아래 요소의 바닥과 캔버스 한계를 비교해 여유(px)를 찍는다.

슬라이드마다 **두 가지**를 잰다 — ① 내용이 캔버스를 넘쳤는가 ② **폭이 고정된 라벨 칸이 두 줄로 접혔는가.**

- **라벨 줄바꿈** → `.k`(116px)·`.c`·`.svc .k` 처럼 폭이 고정된 칸에 글자가 많은 것이다.
  **칸을 넓히지 말고 글자를 줄이고, 넘치는 말은 옆 설명 칸으로 옮긴다.** 분량 기준은 `assets/components.md` §7.
- **여유가 음수 = 넘침** → 항목을 줄이거나 슬라이드를 나눈다. **폰트를 줄이지 않는다**(원칙 2).
- **본문 슬라이드의 여유 0 은 정상이다.** 내용 컨테이너가 `flex:1` 로 캔버스를 꽉 채우기 때문이다. 표지는 세로 가운데 정렬이라 여유가 크게 나온다.
- 중첩 상자(패널 안 목록 등)가 자기 칸을 넘어선 경우도 음수로 잡힌다.

> **이 검사기는 `[data-anim]` 을 먼저 중화한다.** 비활성 슬라이드의 `data-anim` 요소는 등장 전 상태(`translateY(18px)`)로 누워 있어서, 중화하지 않고 재면 **모든 슬라이드가 일정하게 넘친 것처럼 보인다.** 값이 여러 장에서 똑같이 나오면 내용 탓이 아니라 측정 탓을 먼저 의심한다.

### 5. 문체 점검 (필수)

제목·부제·배너만 뽑아 한 줄씩 늘어놓고 읽는다. 추출 명령과 판정 기준은 `assets/tone.md` 의 **마감 점검**.
화면은 한 장씩 보여주기 때문에 **반복은 나란히 놓아야만 보인다.**

- 인접한 두 장이 같은 결론에 착지하면 → 뒷장을 되받아치는 장으로 뒤집는다
- `—` 뒤에서 앞말을 다시 설명한 곳이 세 곳을 넘으면 → 공식에 빠진 것이다. 한 번에 고친다
- 제목의 절반 이상이 `…입니다` 요약이면 → 명사구로 내린다

### 6. 검증 (필수)

- [ ] `slidecheck` 판정이 **통과**인가
- [ ] `slidecheck` 의 **라벨 줄바꿈**이 0건인가 (고정폭 칸이 두 줄로 접히면 아래가 잘린다)
- [ ] `tone.md` 진단표의 형태(대구·격언·선언형 제목·과장·훈계)가 남아 있지 않은가
- [ ] 출처 없는 비율·기간·인원을 지어내지 않았는가
- [ ] 브라우저에서 `←/→`·`↑/↓`·`Home/End`·`F`(전체화면)가 동작하는가
- [ ] **좌하단 바의 각 칸을 눌러 그 부로 뛰는가.** 표지·목차에서도 눌리는가(거기서 감추면 안 된다)
- [ ] 좌하단에 **현재 부·부 진행바·전체 페이지**가 뜨고, 부 표시는 표지·목차·마무리에서 접히는가
- [ ] 본문 슬라이드마다 `data-n` 이 있고, 표지·구분에는 없는가
- [ ] 표지의 라벨 배지가 **가로로 늘어나지 않았는가**(`.slide` 는 flex column 이라 `align-self:flex-start` 가 필요하다 — 템플릿에 있으니 지우지 않는다)
- [ ] `opacity`·그라데이션 텍스트·색 리터럴을 새로 만들지 않았는가
- [ ] 미치환 `{{...}}`·오타·깨진 태그가 없는가

### 7. PDF
필요하면 헤드리스로 뽑는다(브라우저 인쇄 대화상자의 머리글·바닥글 문제가 없다). 인쇄 CSS 는 이미 들어 있어 슬라이드 하나가 한 페이지가 된다.

```
"<크롬경로>" --headless --disable-gpu --no-pdf-header-footer --virtual-time-budget=12000 --print-to-pdf="<절대경로.pdf>" "<절대경로.html>"
```

## 내비게이션

**화면 위 조작부가 없다.** 상태를 읽는 자리와 누르는 자리가 좌하단 하나로 합쳐졌다.
(원본 html-slides 의 하단 가로 바도, 이전 판의 오른쪽 세로 레일·점·버튼도 없앴다.)

| | |
|---|---|
| 부 이름 | 좌하단 맨 위 — 현재 `제N부 · 이름`. 부에 속하지 않는 장(표지·목차·마무리)에서는 이름만 감춘다(`visibility`, 자리는 유지) |
| 부 진행바 | **부 수만큼 칸으로 쪼갠다.** 지난 부는 꽉, 현재 부는 진행분만, 남은 부는 빈 칸 — 한 요소가 `전체 몇 부 중 어디`와 `그 부 안에서 얼마나`를 동시에 진다 |
| **바 클릭** | **칸을 누르면 그 부로 뛴다.** 칸 안에서 누른 가로 위치가 그 부의 몇 번째 장인지를 정하므로 **모든 장에 닿는다.** 칸은 16px 높이의 누를 자리, 보이는 3px 선은 그 안의 `span` 이다 |
| 전체 페이지 | 좌하단 맨 아래 `현재 / 전체`. 오른쪽 세로 진행바는 없앴다 — 같은 것을 두 번 그리지 않는다 |
| 키보드 | `←/→`·`↑/↓`·`Space`·`PageUp/Down` 이동, `Home/End` 처음·끝, `F` 전체화면 |
| 터치 | **가로** 스와이프 |
| 딥링크 | `#12` 로 12장부터 연다. 이동할 때마다 주소가 따라 바뀐다 |

> **바는 모든 장에서 보인다.** 표지·목차에서 감추면 거기서 부로 뛸 수가 없다.
> 감출 때 `display:none` 을 쓰면 폭이 0 이 되어 클릭 계산이 `NaN` 이 되고,
> `go(NaN)` 이 **활성 슬라이드를 통째로 없앤다.** `go()` 의 숫자 가드를 지우지 말 것.

인쇄에서는 `.hint`·`.brandbar` 가 숨는다.
