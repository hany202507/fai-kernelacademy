# Kernel Academy — 교육자료

재무·회계 실무자를 위한 AI 활용 표준 커리큘럼의 **강의자료 저장소**입니다.
커리큘럼·강의자료·실습 데이터를 공개합니다.

- 사이트: https://kernelacademy.io
- 사이트 소스: https://github.com/hany202507/kernelacademy-web

## 무엇이 있나

| 경로 | 무엇 |
|---|---|
| `교재/` | 과정별 강의자료와 **작성 규칙** |
| `canon/` | 정본 — 6기능(R·C·P·J·V·D) × 7워크플로 |
| `courses/` | 과정 설계 문서 |
| `.claude/skills/` | 강의자료를 같은 형식으로 만드는 Claude Code 스킬 |

## 가르치는 데 쓰시려면

| # | 읽을 것 |
|---|---|
| 1 | [교재/00_교육계획.md](교재/00_교육계획.md) — 과정이 몇 개이고 무엇이 있고 없는지 |
| 2 | [교재/README.md](교재/README.md) — 자료를 어떤 규칙으로 만드는지 |

강의자료를 만들 때는 `.claude/skills/` 의 스킬을 쓰십시오. 저장소 폴더에서 Claude Code 를
띄우면 설치 없이 뜹니다. 저자마다 형식이 갈리지 않도록 디자인을 템플릿에 박아 두었습니다.
