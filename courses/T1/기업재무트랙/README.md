## 기장 트랙과 갈려야 할 지점

| 구간 | A 기장 트랙 | B 기업재무 트랙 (예정) |
|---|---|---|
| 보안 | 위임받은 **고객사** 데이터 — 자체 판단 권한 제한 | **자사** 데이터 — 내부통제·승인 체계 |

| 확산 단위 | 사무소 | 팀 (사내 챔피언 경로) |
