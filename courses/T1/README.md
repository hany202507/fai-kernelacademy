# T1 (12h) — 2트랙 구조

updated: 2026-07-29 · renders-from: [canon/](../../canon/README.md)

T1은 형식(**12시간 · 3일×4h · 이수학점**)을 공유하고 **대상별로 트랙이 갈린다.** 재무 실무자 일반을 한 과정에 담으면 회계사에게는 얕고 기업 재무팀에게는 남의 일이 되기 때문이다.

| 트랙 | 대상 | 관통 업무 | 상태 |
|---|---|---|---|
| **A — 기장 트랙** | **개업 공인회계사 · 회계세무사무소 기장 실무자** | 기장 사이클(수취→분류→대사→신고→결산→회신) | [실라버스 v0.1](기장트랙/00_실라버스_v0.1.md) — 한공회 제안용 |
| **B — 기업재무 트랙** | 기업 재무팀·경리 담당 | 결산·보고·예산 사이클 | 홀딩 — [기업재무트랙/README.md](기업재무트랙/README.md) |

## 공유하는 것 / 갈리는 것

| | 공유 | 갈림 |
|---|---|---|
| 형식 | 12h · 3일×4h · 이수학점 · 정원 35 | — |
| 1일차 개념 | 6블록 문법 · 결정론 프레임 | **보안 층위** — A는 위임받은 고객 데이터, B는 자사 내부통제 |
| 2일차 에이전트 | 에이전트 제작법 · 검증(V) 방법론 | **에이전트 6종의 구성** |
| 3일차 확산 | 라이브러리 · 적용 설계 · 30/90일 플랜 | **확산 단위** — A는 사무소, B는 팀 |

두 트랙 모두 canon의 6블록을 그대로 쓴다. 갈리는 것은 **어느 워크플로로 훈련하느냐**다 — A는 세무·회계결산, B는 보고·예산관리 중심.

## 트랙 분기 결정 경위

[05_교육과정_커리큘럼_v0.9.md:94](../../05_교육과정_커리큘럼_v0.9.md:94)의 T1 골격은 재무 실무자 일반 대상이었다. 9월 한공회 부트캠프의 청중이 회계사·사무소 실무자로 확정되면서, 그 청중에 맞춘 기장 특화판이 필요해졌다. 기존 일반 골격은 폐기하지 않고 **B 기업재무 트랙으로 승계**한다.

> 8월 위원 검토회의 안건: 트랙 분기의 타당성, B 트랙 개시 시점.

## 용어

- **L(급수)** = 과정 등급. T1/T2/T3로 대외 표기.
- **M(모듈)** = 한 과정 안의 구간. 실라버스는 M1, M2… 로 쓴다.
- **트랙** = 같은 급수 안의 대상별 분기. A/B로 표기.
